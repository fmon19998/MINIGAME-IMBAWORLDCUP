## Revisi utama
1. Gameplay front-view dibuat lebih dekat dengan referensi:
   - kiper besar di depan gawang;
   - gawang besar terlihat jelas di belakang kiper;
   - bola datang dari depan ke arah gawang;
   - bola close-up bisa lewat depan kiper seperti poster aksi.

2. Lapangan bola diperbaiki:
   - rumput perspektif;
   - garis lapangan;
   - kotak penalti;
   - kotak gawang;
   - titik penalti;
   - stadion dan lampu lebih sinematik.

3. Gawang diperbaiki:
   - tiang kiri-kanan besar;
   - mistar atas;
   - jaring/net lebih rapat;
   - kedalaman gawang lebih terlihat.

4. Tier mode diperjelas untuk admin:
   - TIER MODE BAYI (SANGAT MUDAH)
   - TIER MODE B AJA (NORMAL)
   - TIER MODE NERAKA (DEWA PUN SUSAH)

5. Mode Neraka dibuat jauh lebih tidak manusiawi:
   - bola sangat cepat;
   - spawn sangat rapat;
   - burst 3 bola tambahan;
   - kontrol kiper berat;
   - area tangkap sangat kecil;
   - bola sering ke sudut;
   - stamina cepat habis.

Catatan: Player tetap tidak melihat mode/tier. Mode hanya untuk admin.
