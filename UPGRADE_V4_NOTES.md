## Fitur yang di-upgrade
1. Zoom in / zoom out arena game untuk smartphone dan PC.
2. Slider zoom + tombol plus/minus + tombol reset zoom.
3. Zoom state disimpan di browser player.
4. Tampilan arena dibuat lebih 3D dengan frame, bayangan, dan depth effect.
5. Canvas game diperbagus: stadion lebih hidup, spotlight, goal post lebih tebal, bayangan bola, dan detail kiper lebih kuat.
6. Toolbar tampilan arena dibuat responsive untuk mobile.
7. Shortcut keyboard untuk zoom saat main:
   - `+` = zoom in
   - `-` = zoom out
   - `0` = reset zoom
